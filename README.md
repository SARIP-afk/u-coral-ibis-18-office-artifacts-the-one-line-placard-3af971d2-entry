A program (Node.js, standard library only) that writes one museum placard line for an ordinary office object treated as an ancient artifact to `/output/entry.txt`.

## The line

> Stapler, c. 1997, pressed steel. Ritual binding device of the open-plan temple; priests fastened prayers no one was ever meant to read again. Gift of a middle manager.

167 characters, no trailing newline.

Why this line: it takes the stapler's real function — binding sheets together — and turns it into theology. The priests of the open-plan temple fastened prayers nobody was ever meant to read again: a specific, surprising imagined history rather than a generic office joke. The wit stays deadpan — the line never explains itself — and the label craft sells it: catalogue date (c. 1997), material (pressed steel), and donor (a middle manager).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Deterministic, no network, two runs byte-identical.
